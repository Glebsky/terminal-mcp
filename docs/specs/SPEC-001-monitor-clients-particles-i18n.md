# SPEC-001 · Recent Clients, частицы Connection monitor, локализация UI

- **Статус:** Реализовано (ожидает ручной проверки T12)
- **Дата:** 2026-11-13
- **Область:** десктопное приложение (`desktop/src/renderer`)

## 1. Контекст и проблема

1. Список **Recent Clients** ограничен `max-height: 140px` — по факту виден один клиент, остальное приходится прокручивать.
2. Частицы в **Connection monitor**:
   - окрашены только по операции → при одной операции все частицы одного цвета;
   - стоят в детерминированных позициях и не отражают направление трафика (входящий и исходящий смешаны);
   - пересоздаются из каждого снимка раз в секунду → когда трафик заканчивается, частицы мгновенно исчезают на середине пути.
3. Интерфейс только на английском (частично — русские подсказки в заголовке окна). Нужен выбор языка: **English / Українська / Русский**.

## 2. Требования

### FR-1 · Recent Clients
- FR-1.1 Список клиентов занимает свободное место панели монитора, минимальная высота — не меньше ~4 строк клиентов (≥ 180px).
- FR-1.2 При большем числе клиентов список прокручивается внутри себя, не ломая раскладку при минимальном размере окна.

### FR-2 · Частицы потока данных (заменено)
> Заменено [SPEC-003](SPEC-003-data-flow-band.md): вместо частиц одна полоса, толщина которой отражает объём трафика. Требования ниже оставлены для истории.
- FR-2.1 **Входящий** трафик (клиент → сервер) — частицы появляются у **левого** края трубы и летят к **правому**.
- FR-2.2 **Исходящий** трафик (сервер → клиент) — частицы появляются у **правого** края и летят к **левому**.
- FR-2.3 Каждая частица получает случайную вертикальную позицию старта/финиша (небольшой дрейф), случайную скорость и случайный цвет из палитры своего направления (холодная — входящий, тёплая — исходящий).
- FR-2.4 Количество новых частиц в секунду пропорционально байтам каждого направления (адаптивный квант, как раньше: «≈ N на частицу»); появление растянуто по секунде, а не пачкой.
- FR-2.5 Уже появившаяся частица **всегда долетает до конца**: снимки только добавляют частицы, удаление — только по окончании полёта.
- FR-2.6 Ограничение числа одновременно живущих частиц (DOM-бюджет), страховочная очистка «зависших».
- FR-2.7 Если анимации интерфейса выключены (настройка или системный Reduced Motion) — статичное отображение без движения и без накопления узлов.
- FR-2.8 Легенда показывает направления (Входящий → / ← Исходящий) и операции.

### FR-3 · Локализация
- FR-3.1 Языки: English (en), Українська (uk), Русский (ru).
- FR-3.2 Переключатель языка в **Настройки → Внешний вид**, применяется мгновенно, сохраняется на устройстве (как настройки анимации), не требует перезапуска сервера.
- FR-3.3 Язык по умолчанию — из языка системы (uk/ru), иначе English.
- FR-3.4 Переведены все тексты рендерера: заголовок окна, панель управления, MCP Endpoints, монитор, логи, настройки (туннели, сервер, безопасность, инструменты MCP).
- FR-3.5 Корректные формы множественного числа для uk/ru; время в списке клиентов — в формате выбранной локали.
- FR-3.6 Полнота словарей проверяется TypeScript (отсутствующий ключ — ошибка компиляции).

### Не входит в задачу
- Сообщения главного процесса Electron (меню трея, системные диалоги) и тексты ошибок, приходящие с сервера/из логов.
- Технические идентификаторы (имена MCP-инструментов, переменные окружения, URL) не переводятся.

## 3. Дизайн

- **Recent Clients:** `.client-list` → `flex: 1 0 180px; max-height: none`; панель монитора остаётся колонкой с прокруткой.
- **Частицы:** новый компонент `FlowPipe` с локальным состоянием `particles[]`. На каждый новый снимок (`sampledAt`) добавляются частицы `{ id, dir, color, y0, y1, duration, delay }`. Движение — CSS-keyframes `particle-inbound` / `particle-outbound` (`animation-fill-mode: both`), удаление — по `animationend` + периодическая страховочная очистка. Лимит — 120 живых частиц.
- **i18n:** `desktop/src/renderer/i18n/` — словари `en.ts` (эталон и источник типа ключей), `uk.ts`, `ru.ts`; `I18nProvider` + хук `useI18n()` → `{ lang, setLang, t, locale }`; интерполяция `{name}`, плюрализация через `Intl.PluralRules` (формы через `|`). Хранение в `localStorage` (`mcp-terminal-language`), `<html lang>` синхронизируется.

## 5. Критерии приёмки
- В Recent Clients одновременно видно ≥ 4 клиентов при стандартном размере окна.
- При запросах слева направо летят частицы входящего трафика, справа налево — исходящего; цвета различаются; при остановке трафика частицы долетают и только потом исчезают.
- В настройках можно выбрать EN/UK/RU; весь интерфейс рендерера переключается сразу и сохраняет выбор после перезапуска.
