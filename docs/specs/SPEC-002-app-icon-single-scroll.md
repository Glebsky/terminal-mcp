# SPEC-002 · Новая иконка приложения, единая прокрутка монитора

- **Статус:** Реализовано (ожидает ручной проверки T7)
- **Дата:** 2026-11-13
- **Область:** десктопное приложение (`desktop/`)
- **Связано:** SPEC-001 (заменяет FR-1.2 и дизайн `.client-list`)

## 1. Контекст и проблема

1. Иконка приложения (планета, станция, панели) перегружена деталями: на 16–32 px читается плохо и не отражает суть — терминал, доступный через MCP.
2. На вкладке **Монитор** три вложенные области прокрутки: `.dashboard` → `.monitor-panel` → `.client-list`. У списка клиентов стоит `overscroll-behavior: contain`, поэтому когда курсор над списком, колесо мыши не прокручивает главное окно — «окно в окне».

## 2. Требования

### FR-1 · Иконка
- FR-1.1 Современная минималистичная иконка: скруглённая плашка, приглашение терминала `>` + курсор `_`, индикатор активного подключения (зелёная точка в стиле `status-dot`).
- FR-1.2 Палитра согласована с интерфейсом (тёмно-синий фон, бирюзово-голубой градиент, акцент `#71DEB1`).
- FR-1.3 Три варианта под размеры: `icon.svg` (48 px+ и icon.png), `icon-32.svg` (24–40 px, заголовок окна), `icon-16.svg` (16–20 px, выровнен по пикселям).
- FR-1.4 `icon.ico` и `icon.png` пересобираются командой `npm run icons`; пути и конфигурация сборки не меняются.

### FR-2 · Прокрутка
- FR-2.1 В окне ровно одна вертикальная область прокрутки — `.dashboard`; колесо мыши прокручивает окно в любой точке вкладки «Монитор», включая список клиентов.
- FR-2.2 Панель монитора растёт по содержимому (не меньше свободной высоты рабочей области), без собственной прокрутки.
- FR-2.3 Список **Recent Clients** показывает всех клиентов (сервер хранит не больше 50) без внутренней прокрутки.
- FR-2.4 Вкладка «Логи» и пауза мониторинга не меняются.

### Не входит в задачу
- Вынос клиентов в отдельную вкладку — запасной вариант, если единая прокрутка окажется неудобной при большом числе клиентов.

## 3. Дизайн

- **Иконка:** плашка `rx=56` (на 256), градиент `#1E2F5E → #0A1129`, светлая кромка сверху; глиф `>_` с градиентом `#9FF0E6 → #8FA8FF` и мягким свечением; точка подключения `#71DEB1` с кольцом в правом верхнем углу. На 16 px — без свечения и кольца.
- **CSS (`liquid-glass.css`):**
  - `.monitor-panel`: убраны `overflow-y:auto`, `height:100%`, `min-height:0`; добавлено `flex:1 0 auto`.
  - `.client-list`: убраны `overflow-y`, `min-height`, `flex: 1 0 196px`, `overscroll-behavior:contain`; `flex:none`.
