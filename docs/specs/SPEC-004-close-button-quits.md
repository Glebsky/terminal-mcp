# SPEC-004 · Крестик закрывает приложение и останавливает сервер

- **Статус:** Реализовано (ожидает сборки portable и ручной проверки, T6–T7)
- **Дата:** 2026-11-20
- **Область:** десктопное приложение (`desktop/`)
- **Связано:** USER_GUIDE.md, USER_GUIDE_RU.md (раздел «Системный трей»)

## 1. Контекст и проблема

Крестик (`X`) в заголовке окна сворачивает приложение в трей, хотя рядом есть отдельная кнопка «Свернуть в трей» (`ArrowDownToLine`). Две кнопки делают одно и то же, а чтобы выйти по-настоящему, нужно открывать меню трея → «Выход из приложения».

## 2. Требования

### FR-1 · Закрытие
- FR-1.1 Крестик останавливает MCP-сервер, если он запущен или запускается, и завершает приложение.
- FR-1.2 Alt+F4 и «Закрыть окно» на панели задач ведут себя так же: любое закрытие окна означает выход.
- FR-1.3 Окно исчезает сразу; процесс завершается, когда сервер освободил порт и туннель (не позже принудительной остановки `ServerManager` через 3 с).
- FR-1.4 Пока идёт выход, клик по значку в трее и повторный запуск приложения не возвращают окно.
- FR-1.5 Подсказка крестика на en/ru/uk говорит, что сервер будет остановлен.

### FR-2 · Трей (без изменений)
- FR-2.1 Свернуть в трей с работающим сервером можно кнопкой `ArrowDownToLine` и пунктом меню трея «Скрыть окно в трей»; уведомление «Приложение свернуто в трей…» показывается только в этом случае.
- FR-2.2 Пункт «Выход из приложения» в меню трея идёт тем же путём выхода, что и крестик.

## 3. Дизайн

- `desktop/src/main/index.ts`: `quitApp()` ставит `isQuitting`, прячет окно и вызывает `app.quit()`. Её вызывают обработчик `close` окна (вместо `hideMainWindow()`), IPC `window:close`, IPC `app:quit` и пункт трея «Выход из приложения».
- Остановка сервера не меняется: `before-quit` держит выход, пока `serverManager.stop()` не завершится.
- `showMainWindow()` и `toggleMainWindow()` ничего не делают, пока выставлен `isQuitting`.
- Рендерер не меняется: крестик по-прежнему вызывает `closeWindow()`, меняется только текст подсказки.

## 5. Критерии приёмки

- AC1. Сервер запущен → крестик → окно пропадает сразу, процесс завершается, `GET /health` на порту сервера не отвечает.
- AC2. Сервер остановлен → крестик → приложение закрывается без задержки.
- AC3. Alt+F4 ведёт себя как крестик.
- AC4. Кнопка «Свернуть в трей» → окно скрыто, сервер отвечает на `/health`, меню трея работает.
